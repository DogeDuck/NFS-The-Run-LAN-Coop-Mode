# Updates und Schwierigkeit / Updates and difficulty

## Deutsch

Mit **Launch-Coop.cmd** starten. „Updates automatisch installieren“ ist anfangs aktiv. Der Launcher prüft veröffentlichte TEST-Versionen dieses Projekts und installiert eine neuere Version, sobald Spiel und Server geschlossen sind und ein gültiger Spielordner eingetragen ist. „Nach Updates suchen“ löst die Suche samt möglicher Installation manuell aus. Bei fehlendem Internet bleibt Spielen möglich. Der neue Paketordner wird neben dem alten angelegt; der Starter beim Spiel wird auf die neue Version umgestellt. Alte Sicherungen werden behalten.

Unter Hosten die Schwierigkeit wählen. Sie wird gespeichert und als Server-Wert verwendet; Gäste können sie nicht mit ihrem Profil überschreiben. Die Spielprofile selbst werden nicht umgeschrieben. Im Solo-Modus weiter die Schwierigkeit im Spiel wählen. Die serverseitige Änderung ist offline geprüft, im Spiel noch zu bestätigen.

Kein kompletter Spielinhalt im Download. Spielstände werden nicht zurückgespielt. Die Garage öffnet sich pro Client automatisch. Tankstellen meiden. Die bestehenden Definitive-Edition-Einstellungen und der +25dB-Musikpatch bleiben Bestandteil des Pakets.

## English

Start **Launch-Coop.cmd**. “Install updates automatically” is initially enabled. The launcher checks this project's published TEST releases and installs a newer version when the game/server are closed and a valid game folder is selected. “Check for updates” manually checks and installs if available. You can still play offline. A new package folder is added beside the old one; the launcher shortcut next to the game points to the new version. Existing backups are retained.

Choose difficulty under Host. Your choice is remembered and enforced by the server; guests cannot overwrite it with their profiles. Game profiles are not rewritten. For Solo, continue choosing difficulty in the game. Server changes are verified offline and still need an in-game confirmation.

No full game files are included. No save restore is performed. Each client's garage opens automatically. Avoid gas stations. Existing Definitive Edition settings and the +25dB music patch remain included.
