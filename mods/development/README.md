# Development sources / Entwicklungsquellen

These source files document current work. They require the project dependencies
and are not a complete installation package. Use published release ZIPs to play.
Actor selection and two host milestones improved scene visibility in local R2
tests. Full shared QTE completion and cutscene driving/collision remain under test.
Favorites/presets, session/version tools and opt-in logs are being integrated.

Deutsch: Entwicklungsquellen, nicht manuell ins Spiel kopieren. Kein vollständiger
QTE-Fix behauptet. Das veröffentlichte Installationspaket ist getrennt davon.
